## Conteúdo desta pasta

Em paralelo ao exercício de delegação, DBA e QA verificam novamente a reconciliação
de dados, reexecução/recuperação e a consulta completa de beneficiários. O PO
registra a aceitação ou os bloqueios durante a validação integrada. Uma PR do Agent
não substitui este [gate de aceitação de dados](../docs/DATA-MIGRATION.md).
